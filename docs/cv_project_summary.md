## AML & Fraud Detection Pipeline (SQL + ML)

Built an end-to-end pipeline simulating millions of UK banking transactions.  
Used advanced SQL (window functions, CTEs) to detect structuring, velocity anomalies, and impossible travel.  
Engineered features in SQL, trained XGBoost + Isolation Forest models in Python to score fraud risk, and wrote risk scores back to a SQL dashboard table.  
Aligned with UK FCA/AML priorities on transaction monitoring and financial crime detection.
